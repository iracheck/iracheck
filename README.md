### Dynamic Squad AI Simulation
[GitHub Repository](https://github.com/iracheck/DynamicSimulationMod)

An extensible combat simulation framework built for Grand Theft Auto V that allows large-scale faction battles to run autonomously.

The system was designed around modular game modes and lifecycle hooks, allowing new simulation scenarios to be added without rewriting the core framework. Factions, vehicles, and other simulation parameters can also be configured through `.ini` files.

**Highlights:**
- Modular simulation architecture
- Configurable factions and vehicles
- Custom game modes and lifecycle hooks
- Designed for extensibility and performance
- Over 450 downloads

**Technologies:** `C#` `.NET` `ScriptHookV` `LemonUI`

**Timeline:** V1.0 — June-August 2025 · V1.1 — January 2026  
**Status:** Completed · Occasional updates

### PCRemote
[GitHub Repository](https://github.com/iracheck/pcremote-csharp)

A Windows desktop utility that converts game-controller input into mouse and keyboard actions.

PCRemote was designed to make software that normally requires a keyboard and mouse accessible through a standard game controller, while also providing compatibility for applications that do not natively support controllers.

**Technologies:** `C#` `.NET` `WPF` `XAML` `XInput`

**Timeline:** March 2025  
**Status:** Shuttered · Baseline version fully functional
